# houkan-kaitei

訪問看護の診療報酬（医療保険の訪問看護療養費）のルールを、改定ごとの git の履歴にしたリポジトリです。
**1コミット＝1つの出来事**（改定、または疑義解釈）で、コミット日はそのルールで請求が始まる日です。前回の改定から何が変わったかを、PDF を見比べる代わりに `git diff` で読めます。

```sh
git log --format="%ad %s" --date=short        # 出来事の一覧
git diff R06 R08 --stat                       # 令和6年度→令和8年度で変わったファイル
git diff R06 R08 -- kokuji/01.md              # 訪問看護基本療養費の本文の差分
git diff R06 R08 -- master/kihon-kingaku.tsv  # コード・名称・金額の差分
git log --format="%ad %s" --date=short -- gigi/R08/  # 令和8年度の疑義解釈がいつ出たか
grep -l 包括型 gigi/R08/*.md                    # 包括型訪問看護療養費の疑義解釈がある回
```

> **公式のデータではありません。請求の根拠には使わないでください。** 正しい内容は、官報と厚生労働省の原文で確かめてください。

## 決まりごと

- **タグ**：改定ごとに打ちます（`R06` ＝令和6年度改定）。記事などから指すときはタグを使ってください。
- **追記だけ**：公開後は過去のコミットを書き換えません。厚労省が資料を訂正したときも、訂正を新しいコミットとして足します。
- **疑義解釈**：1回の事務連絡を1コミットにします。適用日より前に出た疑義解釈は、コミット日を適用日にしています（請求のルールとして効くのは適用日からなので）。実際の日付はコミットメッセージの `Issued:` にあります。取り込んでいるのは令和8年度改定の疑義解釈からです。
- **未適用の出来事**：告示は出たがまだ適用されていない改定などは、`upcoming` ブランチ（`main` ＋ 未適用の出来事）に置き、その日が来たら `main` に入れます。`upcoming` は毎日作り直すので、コミットIDではなくブランチ名で参照してください。`main` はいつでも「今日の請求のルール」です。

## 読むときの注意

- **区分番号は改定でずれることがあります。** 令和8年度改定では「訪問看護遠隔診療補助料」が区分番号０６に入り、訪問看護ベースアップ評価料は０６から０７に移りました。`kokuji/06.md` の差分は、同じ項目の変更ではありません。項目を追うときは、マスターのコード（9桁）を使ってください。コードは、廃止や新設されたものを除き、改定をまたいで引き継がれます。
- **マスターの過去版は令和6年度版と令和8年度版しか残っていません。** そのため履歴は令和6年度改定から始まります。令和6年度版は 2024-08-23 更新の版です。
- **マスターはそのままの CSV ではありません。** 配布のたびに全行で変わる列（変更年月日・変更区分）と未使用の列を落とし、繰り返し項目を1列にまとめ、文字コードを UTF-8 にしています。
- **本文は PDF から機械的に作っています。** ルビ（ふりがな）と改行を取り除いて1項目1行にしました。文字は変えていませんが、表の崩れなどが残っている可能性があります。留意事項通知の別紙様式は取り込んでいません。
- **疑義解釈は訪問看護の部分だけです。** 「訪問看護療養費関係」の別添の全部と、「看護職員処遇改善評価料及びベースアップ評価料関係」の別添のうち「訪問看護」を含む問を取り込んでいます。医科の在宅患者訪問看護・指導料（病院・診療所からの訪問看護）の疑義解釈は入っていません。訪問看護の部分が無い回はコミットがありません。
- **前の改定の疑義解釈で、廃止されていないものも効いています。** 新しい疑義解釈で「…の問○は廃止する」と書かれたもの以外は、令和6年度以前の疑義解釈も引き続き有効です。このリポジトリには入っていないので、厚労省のページで確かめてください。
